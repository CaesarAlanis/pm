# Scripts

Start and stop scripts for the PM app Docker container.

## Files

- start.sh / stop.sh -- Mac/Linux (bash)
- start.bat / stop.bat -- Windows (cmd)
- start.ps1 / stop.ps1 -- Windows (PowerShell)

## Usage

All scripts run from the project root via `cd`. Start builds and runs the container on port 8000. Stop tears it down.
